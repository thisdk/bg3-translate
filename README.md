# BG3 MOD 汉化工具 ✨

一款专为《博德之门 3》（Baldur's Gate 3）打造的桌面端 MOD 汉化工具。无需命令行拆包与繁琐的 XML 手工编辑，只需 **打开 MOD → AI 翻译与校对 → 重新打包** 三步，即可直接生成可在游戏中加载的中文 `.pak` 模组文件。

---

## 核心功能

### 1. 一站式解包与重打包
- **支持 `.pak` 与 `.zip` 直开**：可直接选择或拖入 `.pak` 模组文件，也支持直接拖入从 Nexus Mods 下载的 `.zip` 压缩包（自动识别并提取其中的 `.pak`）。
- **覆盖三种 BG3 本地化格式**：
  - `Localization/*/*.xml`（最常见的标准本地化文本表）
  - `*.loca`（编译后的二进制本地化表）
  - `*.lsx`（自动仅提取 `DisplayName`、`Description` 等玩家可见文本字段，严格跳过 `Name` 等脚本内部标识符，防止破坏模组逻辑）
- **无损重打包**：打包时自动将译文写入 `Localization/Chinese/` 目录，原封不动保留 MOD 内的脚本、贴图、模型及原语言兜底文件，默认输出 `<原文件名>_zh.pak`。
- **纯解包模式**：首页额外提供「仅解包到文件夹」功能，方便仅需拆包查看或提取资源的玩家使用。

### 2. 专为 BG3 设计的结构保真与防坏档机制
- **标签与占位符严密校验**：逐条比对原文与译文的 `[1]` / `{1}` 动态参数占位符、`<LSTag ...>` 富文本标签及属性、`<br>` 换行符数量；同时严防大模型误翻 `Tooltip="SavingThrow"`、`Type="Status"` 等游戏内部查表键值。
- **常见符号偏差自动修复**：模型偶发将半角 `[1]` 输出为全角 `［1］` 时自动归一化修正。
- **带原因自动纠错重试**：当某条译文漏掉标签或改坏占位符时，工具会自动附带具体错误原因要求模型重新生成，大幅降低千条级大文本 MOD 的出错率。
- **打包安全兜底**：未翻译或最终未通过结构校验的条目，在打包时会自动退回英文原文，绝不将残缺标签写入 `.pak` 导致游戏内乱码或崩溃。

### 3. BG3 专有术语表与上下文一致性
- **内置与自定义术语库**：内置《博德之门 3》核心专有名词（角色、地名、职业、法术、D&D 规则术语），支持关键词搜索、单条增删改、恢复默认，以及一键导入外部 JSON 术语表（导入时自动过滤不适合做硬性约束的短词、长句和带标签词条）。
- **按需精准注入**：翻译每条文本时仅注入该条实际命中的术语，节省 Token 且避免无关词条干扰模型。
- **自动复用与增量汉化**：同一 MOD 内相同原文自动复用译文；`Body 1` ~ `Body 4` 等系列变体词条自动保持命名规律一致；若原 MOD 已自带部分中文（`Localization/Chinese`），打开时会自动合并为已完成底稿，仅需翻译剩余未汉化条目。
- **本 MOD 语境提示**：支持为当前 MOD 填写一段背景或风格说明（如装备派系、任务基调、说话口吻），让整轮翻译贴合模组设定。

### 4. 流畅的翻译与人工校对工作台
- **高并发流式预览**：支持自定义并发数（1~32），实时滚动显示每条文本的生成过程、完成进度、成功/失败计数与耗时，随时可暂停取消。
- **单选语言防误触**：左侧文件树自动将 `English` 语言文件置顶，并采用单选模式，避免多国语言包混选互相覆盖；翻译进行期间自动锁定文件切换、底部打包与行内操作按钮，防止并发写冲突。
- **整轮翻完后精准精修**：翻译结束后，可按「全部 / 待翻译 / 已完成 / 出错」状态筛选或搜索关键词，支持**一键重试所有失败条目**、**单条重试**、**行内手动编辑译文**（保存时实时校验标签结构）以及**一键还原原文**。
- **多套界面主题**：内置「浅色」「暖沙」「暗夜」「幽暗地域」4 套配色主题，随时一键切换。

## 下载与安装

前往项目的 [Releases](../../releases) 页面下载最新版本的 Windows 64 位安装包：

- **便携版**（`*-Portable.zip`，**推荐**）：解压到任意目录后直接运行 `bg3-translate.exe`，配置与术语表默认保存在同级目录，升级或备份最为方便。
- **EXE 安装程序**（`*-Setup.exe`）：常规向导式安装。
- **MSI 安装包**（`*-Installer.msi`）：Windows 标准安装包。

## 使用教程

### 1. 打开 MOD 文件
启动软件后，点击 **「打开并汉化 MOD」** 选择 `.pak` 或 `.zip` 文件，也可以直接将文件拖入窗口。
> 如果你只想把 `.pak` 解包成普通文件夹查看内容，可以点击右侧的「仅解包到文件夹」。

<img width="1800" height="1200" alt="选择 MOD 文件" src="https://github.com/user-attachments/assets/c9ebb1b8-dfad-4b1b-bb70-73dc7978b92f" />

### 2. 配置大模型接口
点击右上角 **「设置」** 按钮，配置兼容 OpenAI 接口规范的大模型服务：

| 配置项 | 说明与示例 |
| --- | --- |
| **API 地址 (Base URL)** | 例如 DeepSeek 填 `https://api.deepseek.com`，OpenAI 填 `https://api.openai.com/v1`，本地 Ollama 填 `http://127.0.0.1:11434/v1` |
| **API Key** | 对应服务商后台申请的密钥（本地免鉴权服务可任意填写） |
| **模型名称 (Model)** | 例如 `deepseek-chat`、`gpt-4o-mini` 等 |
| **并发数** | 同时翻译的请求数量（建议 `4` ~ `8`，视接口速率限制而定） |
| **温度 (Temperature)** | 建议保持 `0.3` 左右，兼顾译文自然度与标签结构稳定性 |

<img width="1800" height="1200" alt="配置大模型接口" src="https://github.com/user-attachments/assets/158aa36a-b31f-4736-98a0-d90273c21326" />

### 3. 选择语言文件并开始翻译
1. 在左侧文件列表中**单选**需要翻译的源语言文件（通常直接选择排在第一位的 `English` 语言文件即可）。
2. （可选）如果该 MOD 有特定的背景设定，可以在上方 **「本 MOD 语境」** 输入框中填写简短提示，模型会按该设定调整用词风格：
   <img width="1800" height="322" alt="填写 MOD 语境提示" src="https://github.com/user-attachments/assets/d1755cc9-6345-4ee3-b74f-1f7ee831c842" />
3. （可选）点击右上角 **「术语表」** 可查看、添加固定译名或导入自定义 JSON 术语表。
4. 点击 **「开始翻译」**（或「翻译剩余 N 条」），右侧表格会实时展示流式翻译进展。

<img width="1800" height="1200" alt="选择文件并开始翻译" src="https://github.com/user-attachments/assets/08986436-d270-40fc-962e-677dd48a8fda" />

### 4. 检查与人工校对
整轮翻译完成后：
- 若有少量条目因接口波动或结构校验未通过而标红，可点击上方筛选栏的 **「出错」** 标签页，点击 **「重试失败」** 批量重翻，或点击单行右侧的 **「重试」**。
- 如需手动润色某条文本，点击该行右侧的 **「编辑」** 即可直接修改译文并保存（支持 `Ctrl + Enter` 快捷保存、`Esc` 取消）；点击 **「还原」** 可恢复为未翻译状态。

### 5. 完成翻译并重新打包
确认译文无误后，点击右下角 **「完成翻译，去打包」**，确认导出路径并点击 **「开始打包」**。
软件会生成 `<原文件名>_zh.pak` 文件，将其放入游戏 MOD 目录并通过 BG3ModManager 或游戏内置模组管理器启用即可。

<img width="1800" height="1200" alt="重新打包导出" src="https://github.com/user-attachments/assets/f37730ec-e661-47ea-bc21-174d9b0a13b9" />

## 配置文件与术语表位置

软件默认采用便携优先策略：
- 当 `bg3-translate.exe` 所在目录可写时（例如使用便携版解压在桌面或常用磁盘），所有数据统一保存在程序同级的 **`config/`** 文件夹下：
  - `config/settings.json`：大模型接口设置
  - `config/glossary.json`：术语表数据
- 备份或迁移软件时，只需保留这个 `config/` 文件夹即可。
- 若程序被安装在无写入权限的系统受保护目录（如 `C:\Program Files`），则会自动回退至系统用户目录 `%APPDATA%\com.bg3translate.app\`。你随时可以在右上角「设置」弹窗底部查看当前实际生效的存储路径。

## 常见问题 (FAQ)

**Q：为什么翻译完成后有个别条目显示「译文结构校验未通过」？**
> A：《博德之门 3》的文本包含大量 `<LSTag>` 标签与 `[1]` 动态数值占位符，一旦缺失或属性名被模型改写，游戏内就会显示乱码甚至闪退。遇到此类报错条目，只需在整轮翻译完成后切换到「出错」列表，点击「重试」让模型重翻，或点击「编辑」手动补齐缺失的标签/占位符即可。

**Q：为什么有些 MOD 打开后提示没有可翻译的语言文件？**
> A：部分纯外观替换、贴图或脚本修复类 MOD 本身不包含任何新增文本（即不含 `Localization` 语言表或带文本的 `.lsx`），这类 MOD 在中文客户端下本就不会显示英文，无需汉化。

**Q：翻译中途遇到网络超时或 `HTTP 429`（请求过于频繁）怎么办？**
> A：软件内置了自动退避重试机制。如果服务商限流较严，可以在右上角「设置」中将 **并发数** 调低（例如改为 `2` ~ `4`），然后在翻译界面点击「重试失败」或「翻译剩余条目」继续即可，已翻译成功的条目会自动保留，不会重复消耗 Token。

**Q：打包生成的 `_zh.pak` 应该怎么用？**
> A：生成的 `<原名>_zh.pak` 已经完整包含了原 MOD 的所有功能文件与新增的中文语言包，**直接用它替代原英文 `.pak` 放入游戏 MOD 目录加载即可**，无需同时勾选原版与 `_zh` 两个包。
